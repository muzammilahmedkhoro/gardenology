Gardenology JavaScript Website

This is a JavaScript Single Page Application (SPA).

Files:
- index.html: only the app shell
- css/styles.css: all design and responsive styling
- js/app.js: all pages, navbar, footer, routing, shop, cart, forms

Pages inside the JavaScript app:
- Home
- Categories
- Shop
- Cart
- Become Seller
- Contact
- Dashboard
- Privacy Policy

How to run:
1. Open this folder in VS Code.
2. Install Live Server extension if you do not have it.
3. Right click index.html.
4. Click Open with Live Server.

Important:
This is frontend JavaScript only. Cart is saved in browser localStorage.
Checkout, payment, user login and real order saving need backend integration later.
